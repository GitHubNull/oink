# 任务转交文档

本目录保存跨会话、跨 AI 编程代理的任务转交记录。每份文档必须自包含：接手者不需要本目录之外的历史对话。

## 命名与结构

- 文件名：`YYYY-MM-DD-<范围>-<主题>.md`，例如 `2026-11-17-linux-x11-port.md`。
- 新转交新建文件，**不要覆盖或删除旧文件**；旧文件是当时状态的快照。
- 长期计划正文放在 `doc/linux-x11/plan.md`（或对应领域目录），实施记录追加到计划文件，不要只留在对话里。
- 本 README 的索引表在每次新增交接文档时更新。

## 每份转交文档至少包含

1. 日期、仓库、基线环境、当前 HEAD 与 git 状态。
2. 一句话状态，明确“已完成 / 进行中 / 未开始”，禁止把探针或编译通过写成产品功能通过。
3. 任务表：ID、范围、状态、证据或下一步。
4. 已验证证据：命令、结果、日志路径；未验证项单列。
5. 产品代码现状：按 crate/文件给 `path:line` 证据和缺口。
6. 环境手册：工具链路径、依赖检查、隔离测试入口、代理、资源限制、构建/验收命令。
7. 已知坑与平台限制。
8. 用户红线与禁止事项。
9. 验收标准（DoD）与待用户确认项。
10. 交接记录表（日期 / 代理 / 范围 / 结果 / 产物）。
